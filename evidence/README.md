# Evidence Directory

Store exported real JSON/CSV samples and redacted runtime inventories here. Generated evidence files are ignored by Git. Each evidence set should state UTC timestamp, operator, scenario, browser/test origin, city/ISP if known, destination, git commit, app image/version, AWS account alias or redacted ID, exact AZs, warm-up/sample count, concurrency, payload, connection reuse policy, and errors.

Never edit a saved trace and continue calling it live. A future replay must be prominently labeled `RECORDED` with the original timestamp.
